# 카드 내역 CSV 형식

앱 **월별 입력 → 카드 내역 CSV 가져오기**는 두 가지 파일을 받습니다. 파일은 기기 안에서만 읽고, 월별·공제 구분별 **합계만** 저장합니다.

## 1. 정규화 형식 (6번 고정비 파이프라인 → 이 앱)

6번 파이프라인이 이 형식으로 내보내면 그대로 연결됩니다. 간편결제(네이버페이·카카오페이 등) 경유 내역은 6번의 "간편결제 내역 합치기" 단계에서 실제 결제수단으로 바꾼 뒤 내보내세요. 그래야 이중 집계가 생기지 않습니다.

```csv
date,amount,merchant,method,deduction
2026-05-01,10000,동네시장 상회,debit,market
2026-05-02,1450,서울교통공사,credit,transit
2026-05-03,-5000,스타벅스,credit,general
```

| 열 | 값 |
| --- | --- |
| `date` | `2026-05-01`, `2026.05.01`, `20260501` 등 |
| `amount` | 원 단위. 취소는 음수 |
| `merchant` | 가맹점명 (`deduction` 이 없을 때 자동 분류에 사용) |
| `method` | `credit` / `debit` / `cash_receipt` (또는 신용·체크·현금영수증) |
| `deduction` | `general` / `market` / `transit` / `culture` / `excluded` (또는 일반·전통시장·대중교통·도서공연·제외) |

## 2. 카드사 이용내역

카드사 앱·홈페이지에서 이용내역을 엑셀로 받아 **CSV로 저장**하세요. EUC-KR 인코딩도 읽습니다.
위쪽 안내 문구는 건너뛰고 첫 15줄 안에서 `이용일·이용금액·가맹점` 같은 머리글을 찾습니다.
결제수단 열이 없으면 가져올 때 고른 값(신용/체크)을 모든 줄에 적용합니다.

`deduction` 열이 없으면 가맹점명으로 분류합니다. 이 분류는 **추정**이라 미리보기에서 확인해야 합니다.

- 대중교통: 버스, 지하철, 코레일, KTX, SRT, 티머니, 캐시비 등
- 전통시장: `○○시장`, 전통시장, 상점가
- 도서·공연 등: 서점, 교보문고, 예스24, CGV, 메가박스, 공연, 박물관, 미술관, 체육시설
- 공제 제외: 세금·공과금, 관리비, 보험료, 상품권, 통행료, 하이패스, 면세점, 해외

카드가 여러 장이면 파일을 하나로 합치거나, 두 번째 파일부터 "더하기"를 고르세요.
